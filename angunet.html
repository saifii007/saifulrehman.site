ANGUNET

ANGUNET is a full-stack portfolio project founded by Saif Ul Rehman. It brings Angular, ASP.NET Core, Docker, npm scaffolding, and an MCP server into one clean developer-ready starter.

Technology Stack

Angular UI

Layered frontend folders for core logic, data services, features, shared components, directives, pipes, and validators.

ASP.NET Core

Clean backend structure with API, Application, Domain, and Infrastructure projects ready for real services.

SQL + MongoDB

Database-ready foundation for relational and document persistence patterns.

CLI + MCP

Published npm generator plus a project MCP server for startup help and AI tooling context.

Create Project

npx angunet myapp

Generates the Angular + .NET starter with the ANGUNET folder structure.

Run Locally

npm start

Starts the Angular UI while the .NET API runs on its local backend port.

MCP Server

node mcp-server/server.js

Exposes project resources, startup commands, and environment URLs to MCP clients.
